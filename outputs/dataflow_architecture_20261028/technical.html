01 / DATAFLOW NAVIGATOR

先選視角，再點選節點

箭頭表示資料依賴；非所有支線都按時間串行。窄螢幕可左右捲動架構圖。

資料／程式連接人工／參考支線

關鍵區分 A

數字來源是 SEC；BQ 是儲存與核對層

XBRL 提供財務事實，10-K／10-Q 提供原文。BigQuery 與 dbt 不創造公司財務數字，也不取代來源證據。

關鍵區分 B

「變動多少」與「為何變動」不同

正式 build_narratives() 目前只組合數值比較。CDW 的原因由額外模型分析、原文覆核及 passage 綁定補上。

關鍵區分 C

程式跑通，不代表財務驗收通過

CDW 的雲端及輸出階段完成，仍因總額利息、速動資產、LTM 與勾稽缺口而保留為 draft。

03 / SOURCES & STORAGE

資料從哪裡來，最後存在哪裡？

PRIMARY SOURCES

SEC EDGAR 與經覆核補查

  • data.sec.gov/submissions/CIK{cik}.json：公司、ticker、申報日期及文件索引。
  • data.sec.gov/api/xbrl/companyfacts/CIK{cik}.json：標籤、金額、單位、起訖日、accession。
  • sec.gov/Archives/edgar/data/…：10-K／10-Q 原始 HTML、MD&A 與附註。
  • supplement.json：本次公司來源核對後的定義、金額、定位與驗證紀錄；不是另一家公司的樣板數字。

CDW CIK：0001402057。四期保留 FY2024、2025 Q2、FY2025、2026 Q2；損益比較採兩個六個月 YTD。

FORMAL CLOUD STORAGE

BigQuery · sec_raw

專案：focus-heuristic-438521-v4。正式路徑以 run_id + entity 隔離每次執行。

  • raw_review_sources：request／metadata、候選 inputs 與 evidence。
  • raw_review_results：canonical Report、Fact、Evidence、Acceptance。
  • raw_review_runs：階段狀態、輸出路徑、完成／草稿／失敗紀錄。
  • stg_loan_review_run_sources：dbt 來源 view；讀回檢查 JSON 是否完全一致。

append-only 原始紀錄；dbt 依 run/key 整理，不跨來源版本加總。Decimal 原值以 payload 字串保留。

04 / TOOLCHAIN

用了哪些工具，各自負責什麼？

工具／技術任務邊界與實際使用
Python + requests透過 SECEdgarClient 讀取 SEC API；下載申報 HTML。核對公司 CIK、期間、unit、accession；來源文件內文字不作為執行指令。
Decimal + dataclassesFact／Period／Evidence／Narrative／Report 結構、金額計算與原始精度。顯示時才四捨五入；缺少、衝突、無法計算、不適用分開處理。
google-cloud-bigqueryrun-scoped staging、精確讀回、結果發布與 run manifest。CDW 兩個 run 均有實際成功紀錄。不是只根據資料表存在就宣稱落地成功。
dbt-bigquerydbt run、dbt test；來源 view 與五個正式 marts。正式 marts 是 Report 的投影：Facts、Evidence、關聯、Acceptance、Runs；不重新計算信用比率。
Anthropic SDKgenerate_commentary() 讀取清理後 MD&A，回傳各主題原因。本機程式設定 MODEL = "claude-opus-5"；CDW 回傳 8 主題。正式 run_review() 不會自動呼叫；本次另行執行並覆核。
Node + @oai/artifact-tool產生 Excel、建立公式、重算、核對 canonical 值、render 預覽與 export XLSX。使用 bundled runtime；已驗證原值修改、空白與零值。未在原生 Microsoft Excel 測試。
Flask／Shell／GitHTTP 與 shell 提供正式入口；Git 區分工作分支及程式版本。本次 CDW 是 CLI + 個案覆核腳本；沒有部署 Flask。頁面反映工作樹，包含未提交的 integration 檔。
